Acerca de la Estructura y la Organización

Este proyecto demuestra la organización profesional de contenido utilizando HTML5. Es crucial entender cómo las etiquetas semánticas mejoran la accesibilidad y el SEO. Por lo tanto, cada elemento ha sido cuidadosamente seleccionado para cumplir con los requisitos del estándar.

Beneficios de las Etiquetas Semánticas:

  • Mejoran la accesibilidad para lectores de pantalla.
  • Facilitan la indexación por parte de los motores de búsqueda.
  • Hacen el código más legible y mantenible.
  • Definen claramente la estructura del documento.

Detalles de Implementación y Recursos

Etiqueta HTML Función Principal
<main> Contenido único y principal del documento.
<section> Agrupación temática de contenido relacionado.
<article> Contenido independiente y autocontenido (e.g., una publicación de blog).

Pasos para el Despliegue en GitHub Pages:

  1. Inicializar el repositorio de Git en la carpeta 'Semana 3'.
  2. Realizar el primer 'commit' con todo el contenido.
  3. Subir los archivos a un repositorio público en GitHub.
  4. Configurar GitHub Pages para desplegar desde la rama principal.
